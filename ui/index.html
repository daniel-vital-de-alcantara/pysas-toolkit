SERVER CATALOG

Refresh libraries & tables

Leave blank for all assigned libraries except WORK, SASHELP and SASUSER. The selected EGP's first program chooses the SAS connection. Initialization runs first, just as in Run a file.

This opens a fresh SAS session and queries metadata. A large catalog or database connection may take time. You can inspect its console or stop its file while it runs.

SAVED SNAPSHOTS

Browse after the run

Browse saved metadata even when SAS is disconnected. Refresh whenever you need an updated picture.

Table storage is disk space reported by SAS, not RAM or available server capacity. Some engines do not report sizes, counts or dates. Totals exclude views and show “at least” when table sizes are missing; library aliases may refer to the same physical tables.

Only libraries assigned in this refresh session are visible. Another job's WORK library is not visible. Dates are the values SAS reports, without a timezone conversion.

Upload to this computer

Files are copied to the selected local folder. Existing files are never replaced. Upload shared initialization files first; jobs uploaded to a running watcher may start immediately.

Move saved data to another version or PC

Download a backup here, then restore it in the new app. Includes all saved run folders, logs, results, command history, bundle downloads, folder settings and saved bundle paths.

Finish commands and stop the watcher first. Input folders, queued files and the app itself are not included. External folder locations may need to be selected again on the new PC. Backups contain your saved code and results.
